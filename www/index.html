About Examination Bills

🩸 App Intro

Free · No ads · No account required · Works offline · No permissions needed

A simple, privacy-first tool for KLS GIT faculty to track examination bill payments. Your data stays on your device.

📖 How to Use

Add a task: Tap the + button, fill in task name, date, units, and rate. Amount calculates automatically.

Track progress: Check off stages in order — Task Completed → Billed & Signed → Payment Received. The task auto-moves to History when fully paid.

View totals: Use the footer toggle to see Active Pending vs Received amounts.

Backup: Tap the database icon to export/import your records as JSON files.

💾 Your Data

All data is stored locally in your browser using LocalStorage. It never leaves your device unless you manually export a backup file.

To backup: Tap the database icon → Download JSON Backup.
To restore: Tap the database icon → select your .json file → Restore Data.
To transfer: Move the .json file via WhatsApp, email, or cloud storage to another device and restore there.
